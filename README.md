# 🚀 Phishing Awareness Lab

## About the Project

The Phishing Awareness Lab is a beginner-friendly cybersecurity awareness training project developed using Python and Flask.

The purpose of this project is to demonstrate how phishing-awareness training works in a controlled environment using fictional credentials.

It helps users understand common phishing warning signs and the importance of protecting their online accounts.

## 🎯 Project Objectives

- Demonstrate phishing-awareness training.
- Educate users about online security threats.
- Explain common phishing warning signs.
- Promote safe online behaviour.
- Practise basic web application development.

## 🛠️ Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- SQLite
- GitHub
- Render

## ✨ Features

- Training homepage.
- Consent-based training demonstration.
- Fictional demonstration accounts.
- Phishing-awareness educational feedback.
- Training activity dashboard.
- Basic event recording.

## 🔐 Security and Privacy

This project is designed strictly for cybersecurity education and awareness.

- Only fictional demonstration credentials should be used.
- Real passwords and verification codes must never be entered.
- The application is not designed to collect or store real account passwords.
- Training should only be conducted with the knowledge and consent of participants.
- Visitor information and dashboard records must be protected.
